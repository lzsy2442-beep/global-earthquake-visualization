数据与方法

数据源：USGS FDSN Event Web Service（earthquake.usgs.gov），按月分块抓取、超限自动二分，按事件编号去重。

  • 时间范围：1995-01-01 至 2026-11-25，统一 UTC 存储，可按北京时间切换显示
  • 时效性：每天 09:17（北京时间）自动抓取 USGS 最新地震，并入地图与统计
  • 震级下限：分别构建 M5.0+ 与 M3.0+ 两套数据集
  • 底图：天地图（矢量 / 地形）与高德，均为国内可访问服务
  • 渲染：MapLibre GL + 主线程 Canvas 叠加层（规避移动端 GeoJSON Worker 挂起）
  • M3 数据以 18 字节/条二进制压缩内联，Base64 还原后解码
